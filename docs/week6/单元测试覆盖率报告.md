## 已知问题

1. **仪器测试缺失**: SecureStorage、Repository、ViewModel 需要 Android 环境
2. **MockK Android**: 部分 Android 框架类无法在 JVM 测试中模拟
3. **EncryptedSharedPreferences**: 需要真实 Android Keystore

## 解决方案

1. 创建 `app/src/androidTest/java/` 目录
2. 使用 `@RunWith(AndroidJUnit4::class)` 运行器
3. 使用 `InstrumentationRegistry.getInstrumentation().context`
4. 配置 AndroidX Test Runner
