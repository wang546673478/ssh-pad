## 4. 测试工具配置

### 4.1 ADB 调试工具

```bash
# 常用 ADB 命令
adb devices                      # 查看连接设备
adb install ssh-pad-v0.1.0.apk   # 安装测试版
adb logcat -s SSHPad:*          # 查看应用日志
adb shell am start -W com.sshpad/.MainActivity  # 启动时间测试
adb shell dumpsys gfxinfo com.sshpad  # 帧率测试
adb shell dumpsys meminfo com.sshpad  # 内存测试
```

### 4.2 性能监控工具

#### Android Studio Profiler
- CPU 占用监控
- 内存占用监控
- 网络流量监控
- 能耗监控

#### 帧率监控
```bash
# 实时帧率监控
adb shell dumpsys SurfaceFlinger --latency com.sshpad

# GPU 渲染分析
adb shell dumpsys gfxinfo com.sshpad framestats
```
