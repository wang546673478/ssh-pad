### 6.3 性能优化建议

#### 已识别瓶颈

1. **帧率略降** (-2fps)
   - 原因：多标签 UI 和 SFTP 进度更新占用资源
   - 建议：优化 Compose 重组，减少不必要的 UI 更新
   - 优先级：P2

2. **10 个标签时内存接近上限**
   - 原因：后台会话缓冲区累积
   - 建议：实现后台会话暂停和缓冲区压缩
   - 优先级：P2

3. **快速切换标签时略卡**
   - 原因：连续触发多次重组
   - 建议：添加防抖和动画优化
   - 优先级：P3

#### 优化计划

| 优化项 | 预期收益 | 工时 | 优先级 |
