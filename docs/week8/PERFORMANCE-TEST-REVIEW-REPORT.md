## 三、多标签内存占用

### 3.1 当前状态

**状态：** ❌ 未实现

**预估内存影响:**

| 组件 | 预估内存 | 说明 |
|------|----------|------|
| TerminalSession 对象 | ~200 bytes | 会话元数据 |
| TerminalBuffer | ~500KB | 80x24 字符缓冲区 |
| ViewModel | ~100KB | 状态管理 |
| UI 组件 | ~2MB | Compose 布局 |
| **单标签总计** | **~2.3MB** | 空闲状态 |

### 3.2 多标签场景预估

| 标签数量 | 预估内存 | 状态 |
|----------|----------|------|
| 1 个标签 | ~55MB | 基于 Week 7 基线 |
| 3 个标签 | ~60MB | +3 个后台会话 |
| 5 个标签 | ~70MB | +5 个后台会话 |
| 10 个标签 | ~90MB | 接近上限 |

**风险:**
- 🔴 高 - 10 个以上标签可能超过 100MB
- 🟡 中 - 后台会话保活需优化

### 3.3 优化建议

1. **后台会话暂停** - 非活动标签暂停渲染
2. **缓冲区压缩** - 减少 scrollback 大小
3. **懒加载** - 标签页按需创建
4. **内存警告处理** - 低内存时清理后台标签

## 四、SFTP 传输性能

### 4.1 当前状态

**状态：** ❌ 未实现

### 4.2 性能要求

| 场景 | 目标 | 说明 |
|------|------|------|
| 小文件上传 (<1MB) | < 2 秒 | 局域网环境 |
| 大文件下载 (>100MB) | > 5MB/s | 局域网环境 |
| 文件列表加载 | < 500ms | 1000 文件目录 |
| 进度更新 | 100ms 间隔 | UI 流畅度 |

### 4.3 技术选型

**Apache MINA sshd-sftp:**

```kotlin
dependencies {
    implementation("org.apache.sshd:sshd-sftp:2.12.0")
}
```

**预估性能:**
- 解析开销：低 (纯 Java 实现)
- 内存占用：中 (通道缓冲区)
- 传输速度：高 (基于 NIO)

### 4.4 实现建议

1. **异步传输** - 使用协程避免阻塞 UI
2. **流式处理** - 大文件分块传输
3. **进度回调** - 定期更新 UI
4. **取消支持** - 支持中断传输
