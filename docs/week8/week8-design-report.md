## 二、多标签会话管理 UI 设计

### 2.1 设计概述

**目标**: 支持用户在同一界面中管理多个 SSH 会话，通过标签页快速切换，提升多服务器操作效率。

**设计原则**:
- 直观 - 标签状态清晰可见
- 高效 - 快速切换、新建、关闭
- 一致 - 遵循 Material 3 和设计系统规范
- 平板优化 - 充分利用大屏空间

### 2.2 核心设计内容

#### 标签页栏设计
- **平板垂直布局**: 左侧 120dp 宽垂直标签栏
- **手机水平布局**: 顶部 56dp 高可滚动标签栏
- **响应式适配**: 根据屏幕宽度自动切换布局

#### 标签项组件
- **尺寸**: 48dp 高度，120dp 宽度（平板）
- **状态指示**: 左侧 3dp 蓝色指示器 + 15% 背景色
- **状态图标**: 已连接（绿）、连接中（黄）、已断开（红）
- **关闭按钮**: 悬停或选中时显示

#### 交互设计
- **切换方式**: 单击、双指滑动、Ctrl+Tab
- **新建方式**: [+ ] 按钮、Ctrl+Shift+T、右键菜单
- **关闭方式**: [×] 按钮、Ctrl+W、中键点击
- **动画**: 切换 200ms，关闭 150ms

### 2.3 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+T | 新建标签 |
| Ctrl+W | 关闭标签 |
| Ctrl+Tab | 下一标签 |
| Ctrl+Shift+Tab | 上一标签 |
| Ctrl+1~9 | 切换指定标签 |

### 2.4 设计亮点

1. **双布局模式**: 平板垂直 + 手机水平，自适应最优布局
2. **状态可视化**: 颜色 + 图标双重表达，一目了然
3. **手势支持**: 双指滑动切换，符合触控习惯
4. **键盘友好**: 全套快捷键，效率优先

## 三、SFTP 文件浏览器 UI 设计

### 3.1 设计概述

**目标**: 提供直观、高效的 SFTP 文件传输功能，支持浏览、上传、下载、管理远程服务器文件。

**设计原则**:
- 直观 - 文件列表清晰，操作入口明显
- 高效 - 批量操作、拖拽传输
- 安全 - 敏感操作确认、权限提示
- 一致 - 遵循 Material 3 和设计系统规范

### 3.2 核心设计内容

#### 文件列表组件
- **列表项**: 64dp 高度，16dp 内边距
- **文件图标**: 32dp，按类型着色（文件夹蓝、文件灰）
- **类型图标**: 8 种文件类型专属图标
- **元信息**: 类型、大小、修改时间

#### 传输进度 UI
- **底部状态栏**: 实时显示上传/下载速度
- **展开面板**: 详细传输队列，支持暂停/取消
- **进度条**: 4dp 高度，状态颜色（蓝/绿/红/黄）
- **速度显示**: 自动单位（B/s、KB/s、MB/s）

#### 交互设计
- **文件操作**: 单击选择、双击打开、长按多选
- **拖拽传输**: 本地↔远程双向拖拽
- **批量操作**: 批量下载（打包 ZIP）、批量删除
- **右键菜单**: 完整文件操作菜单

### 3.3 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+U | 上传文件 |
| Ctrl+D | 下载文件 |
| F2 | 重命名 |
| Delete | 删除 |
| Ctrl+A | 全选 |
| Ctrl+R | 刷新 |
| Backspace | 上级目录 |

### 3.4 设计亮点

1. **双栏并排**: 本地 + 远程同时可见，拖拽直观
2. **类型图标**: 8 种文件类型专属图标，快速识别
3. **实时进度**: 速度 + 进度 + 剩余时间，信息完整
4. **批量操作**: 多选模式，批量下载/删除高效

## 五、问题与修复

### 5.1 P1 级别问题（4 个）

#### UI-021: 标签文本过长未省略
- **模块**: 多标签
- **问题**: 超过宽度的文本被截断，未显示"..."
- **影响**: 用户无法识别长名称标签
- **修复**: 添加 `maxLines = 1, overflow = TextOverflow.Ellipsis`
- **负责人**: 李工
- **状态**: 🔄 修复中

#### UI-025: 手势切换未实现
- **模块**: 多标签
- **问题**: 双指左右滑动手势无响应
- **影响**: 降低操作效率
- **修复**: 实现 `detectTransformGestures` 处理左右滑动
- **负责人**: 李工
- **状态**: 📋 待修复

#### UI-030: 文件类型图标识别度不足
- **模块**: SFTP
- **问题**: 代码文件、配置文件图标区分不明显
- **影响**: 用户需要看扩展名才能识别
- **修复**: 使用更有辨识度的图标（如⚙️配置、📝代码）
- **负责人**: 李工
- **状态**: 📋 待修复

#### UI-034: 传输队列面板无法展开
- **模块**: SFTP
- **问题**: 点击 [展开] 按钮无响应
- **影响**: 无法查看详细进度
- **修复**: 实现队列面板展开逻辑
- **负责人**: 张工
- **状态**: 📋 待修复
