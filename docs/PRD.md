# 产品需求文档 (PRD) v0.1

## 1. 产品概述

### 1.1 产品名称
**SSH Pad** - 安卓平板专用 SSH 客户端

### 1.2 产品定位
专为安卓平板优化的 SSH 客户端，提供优秀的触控体验和键盘支持，让运维和开发工作更高效。

### 1.3 目标用户

#### 用户画像 1：运维工程师 - 张工
- **年龄**: 28 岁
- **职业**: 系统运维工程师
- **场景**: 
  - 出差时需要远程管理服务器
  - 使用平板 + 蓝牙键盘
  - 需要同时开多个 SSH 会话
- **痛点**: 
  - JuiceSSH 免费版功能太少
  - Termux 配置太复杂
- **需求**: 开箱即用、多会话管理、快捷键支持

#### 用户画像 2：开发者 - 李开发
- **年龄**: 25 岁
- **职业**: 后端开发工程师
- **场景**:
  - 在家用平板远程开发
  - 需要分屏（一边查文档一边敲命令）
  - 偶尔需要传文件
- **痛点**:
  - ConnectBot UI 太老旧
  - 没有好的分屏体验
- **需求**: 现代 UI、分屏支持、SFTP 传输

#### 用户画像 3：学生 - 王同学
- **年龄**: 22 岁
- **职业**: 计算机专业学生
- **场景**:
  - 学习 Linux 命令
  - 连接学校服务器做作业
  - 预算有限
- **痛点**:
  - 付费应用太贵
  - 学习曲线陡峭
- **需求**: 免费、易用、有命令提示

### 1.4 使用场景

| 场景 | 频率 | 重要性 | 当前解决方案痛点 |
|------|------|--------|-----------------|
| 远程服务器管理 | 高 | 高 | 多应用切换 |
| 分屏查文档 + 操作 | 高 | 高 | 适配差 |
| 文件传输 | 中 | 中 | 需额外应用 |
| 多会话管理 | 高 | 高 | 切换不便 |
| 快捷键操作 | 高 | 高 | 支持不完整 |

## 2. 功能需求

### 2.1 MVP 功能 (Week 5-10)

#### F1: SSH 连接管理
- **描述**: 支持保存和管理多个 SSH 服务器连接
- **功能点**:
  - 新建/编辑/删除连接
  - 支持密码认证
  - 支持密钥认证 (PEM 格式)
  - 快速连接 (最近连接列表)
  - 连接分组
- **优先级**: P0

#### F2: 终端模拟器
- **描述**: 提供完整的终端体验
- **功能点**:
  - VT100/VT220/ANSI 支持
  - 256 色支持
  - 字体大小调节
  - 深色/浅色主题
  - 触控滚动
  - 复制/粘贴
- **优先级**: P0

#### F3: 会话管理
- **描述**: 管理多个 SSH 会话
- **功能点**:
  - 多标签页
  - 会话切换
  - 后台保活
  - 断线重连
- **优先级**: P0

#### F4: 密钥管理
- **描述**: 安全存储 SSH 密钥
- **功能点**:
  - 导入 PEM 密钥
  - 生成新密钥
  - Android Keystore 加密存储
  - 生物识别解锁
- **优先级**: P0

### 2.2 进阶功能 (Week 11-14)

#### F5: SFTP 文件传输
- **描述**: 支持文件上传下载
- **功能点**:
  - 文件浏览器
  - 上传/下载
  - 进度显示
  - 断点续传
- **优先级**: P1

#### F6: 端口转发
- **描述**: 支持 SSH 隧道
- **功能点**:
  - 本地端口转发
  - 远程端口转发
  - 动态转发 (SOCKS)
- **优先级**: P1

#### F7: 平板专属功能
- **描述**: 针对平板优化
- **功能点**:
  - 分屏支持
  - 双栏布局
  - 物理键盘快捷键 (Ctrl/Alt/F 键)
  - 触控手势
- **优先级**: P1

#### F8: 云同步
- **描述**: 连接数据云端同步
- **功能点**:
  - 账号系统
  - 加密同步
  - 多设备同步
- **优先级**: P2

### 2.3 功能优先级汇总

| 功能 | 优先级 | 工时 (人天) | 阶段 |
|------|--------|-------------|------|
| SSH 连接管理 | P0 | 15 | MVP |
| 终端模拟 | P0 | 12 | MVP |
| 会话管理 | P0 | 8 | MVP |
| 密钥管理 | P0 | 10 | MVP |
| SFTP | P1 | 12 | 进阶 |
| 端口转发 | P1 | 10 | 进阶 |
| 平板专属 | P1 | 15 | 进阶 |
| 云同步 | P2 | 10 | 后续 |

## 3. 非功能需求

### 3.1 性能
- 终端渲染 < 16ms (60fps)
- 连接建立 < 3 秒
- 内存占用 < 100MB
- 冷启动 < 2 秒

### 3.2 安全
- 密钥使用 Android Keystore 硬件加密
- 支持指纹/面部识别解锁
- 无明文存储敏感信息
- 通过第三方安全审计

### 3.3 兼容性
- Android 12+ (API 31+)
- 支持主流 Linux 发行版 SSH 服务器
- 支持平板 (7-13 寸)

### 3.4 可用性
- 新手引导
- 命令自动补全
- 常用命令模板
- 错误提示友好

---

## 4. 技术约束

### 4.1 必须使用
- Kotlin
- Jetpack Compose
- Apache MINA sshd
- Android Keystore

### 4.2 禁止使用
- 过时的 XML 布局 (优先 Compose)
- 不安全的密钥存储方式
- 未加密的网络传输
