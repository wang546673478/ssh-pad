## 1. P0 功能验收清单

### F1: SSH 连接管理

#### 功能验收标准

| ID | 验收项 | 验收方法 | 通过标准 | 优先级 |
|----|--------|----------|----------|--------|
| F1-AC01 | 密码认证连接 | 创建连接并输入密码登录 | 成功登录 Linux 服务器 | P0 |
| F1-AC02 | 密钥认证连接 | 使用 ED25519 密钥登录 | 无需密码成功登录 | P0 |
| F1-AC03 | 新建连接 | 填写主机/端口/用户名/认证信息 | 连接信息保存成功 | P0 |
| F1-AC04 | 编辑连接 | 修改已有连接信息 | 修改后保存成功 | P0 |
| F1-AC05 | 删除连接 | 删除不需要的连接 | 连接从列表移除 | P0 |
| F1-AC06 | 连接保存 | 保存 100+ 连接配置 | 应用重启后数据不丢失 | P0 |
| F1-AC07 | 快速连接 | 从最近连接列表选择 | 一键发起连接 | P0 |
| F1-AC08 | 连接分组 | 创建文件夹分类管理连接 | 连接可按组归类 | P0 |
| F1-AC09 | 连接测试 | Ping 或 SSH 握手测试 | 显示连接可用性结果 | P0 |
| F1-AC10 | 批量导入 | 导入 JSON/CSV 格式连接配置 | 批量导入成功 | P1 |

#### 边界测试

| 测试场景 | 预期结果 |
|----------|----------|
| 连接 100+ 服务器 | 列表加载 < 1 秒，滚动流畅 |
| 主机名含特殊字符 | 正常保存和连接 |
| 端口号非法（0, 65536+） | 输入校验提示错误 |
| 用户名/密码为空 | 保存时提示必填项 |
| 网络断开时尝试连接 | 显示友好错误提示 |
| 连接超时（30 秒） | 显示超时错误，可重试 |

## 2. 性能指标定义

### 2.1 核心性能指标（KPI）

| 指标名称 | 目标值 | 测量方法 | 验收阈值 |
|----------|--------|----------|----------|
| 冷启动时间 | < 2 秒 | 点击图标到主界面可交互 | ≤ 2.5 秒 |
| 连接建立时间 | < 3 秒 | 点击连接到终端可输入 | ≤ 5 秒（网络良好） |
| 终端渲染帧率 | 60 fps | 快速滚动时的帧率 | ≥ 50 fps |
| 输入延迟 | < 50ms | 输入到字符显示的时间 | ≤ 100ms |
| 会话切换时间 | < 500ms | 点击标签到可操作 | ≤ 1 秒 |
| 内存占用（空闲） | < 50MB | 主界面静止时 | ≤ 80MB |
| 内存占用（活跃） | < 100MB | 终端持续输出时 | ≤ 150MB |
| CPU 占用 | < 5% |  idle 状态下 | ≤ 10% |
| 后台保活时长 | 30 分钟+ | 切到后台后保持连接 | ≥ 30 分钟 |
| 崩溃率 | < 1% | Crashlytics 统计 | ≤ 1% |

### 2.2 性能测试场景

#### 启动性能

| 场景 | 测试设备 | 目标值 | 验收标准 |
|------|----------|--------|----------|
| 冷启动（首次安装） | 中端平板（6GB RAM） | < 2.5 秒 | 可通过 |
| 冷启动（旗舰平板） | 高端平板（12GB RAM） | < 1.5 秒 | 可通过 |
| 热启动（后台返回） | 中端平板 | < 1 秒 | 可通过 |

#### 连接性能

| 场景 | 网络条件 | 目标值 | 验收标准 |
|------|----------|--------|----------|
| 局域网连接 | WiFi，低延迟 | < 1 秒 | 可通过 |
| 公网连接 | 4G/5G，中延迟 | < 3 秒 | 可通过 |
| 高延迟连接 | 跨国，200ms+延迟 | < 5 秒 | 可通过 |

#### 渲染性能

| 场景 | 测试方法 | 目标值 | 验收标准 |
|------|----------|--------|----------|
| 快速滚动 | 连续滚动 10000 行输出 | 50+ fps | 无明显卡顿 |
| 大量输出 | cat 大文件（10MB） | 30+ fps | 可中断，不崩溃 |
| 复杂 ANSI | 显示彩色+光标动画 | 50+ fps | 视觉流畅 |

### 2.3 性能测试工具

| 工具 | 用途 | 使用场景 |
|------|------|----------|
| Android Studio Profiler | CPU/内存分析 | 开发阶段性能调优 |
| adb shell dumpsys gfxinfo | 帧率统计 | 渲染性能测试 |
| Firebase Performance | 线上性能监控 | 发布后性能追踪 |
| Crashlytics | 崩溃统计 | 稳定性监控 |

## 4. 验收流程

### 4.1 验收阶段

| 阶段 | 时间 | 参与方 | 产出物 |
|------|------|--------|--------|
| 开发自测 | Week 5-9 每周五 | 开发工程师 | 自测报告 |
| 集成测试 | Week 10 周一 | 测试工程师 | 集成测试报告 |
| 产品验收 | Week 10 周三 | 产品经理 | 验收清单 |
| 安全审计 | Week 10 周四 | 安全顾问 | 安全审计报告 |
| 最终评审 | Week 10 周五 | 全员 | MVP 发布决策 |

### 4.2 验收通过标准

**MVP 发布条件**（所有必须满足）:

1. ✅ P0 功能验收通过率 100%
2. ✅ 核心性能指标达标率 ≥ 90%
3. ✅ 崩溃率 < 1%（内部测试）
4. ✅ 无 Critical/High 级别安全漏洞
5. ✅ 用户体验评分 > 4.0/5.0（内部测试）
6. ✅ 兼容性测试通过（Android 12+ 主流平板）

### 4.3 缺陷分级与处理

| 级别 | 定义 | 处理方式 |
|------|------|----------|
| Critical | 崩溃、数据丢失、安全漏洞 | 必须修复，阻止发布 |
| High | 核心功能不可用 | 必须修复，阻止发布 |
| Medium | 功能有缺陷但有 workaround | 优先修复，可延后 |
| Low | 体验问题、UI 瑕疵 | 排期修复 |
