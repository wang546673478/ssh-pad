# UI 设计方向 v0.1

## 1. 设计风格

### 设计语言
- **Material Design 3** (Material You)
- **动态配色** (跟随系统壁纸)
- **深色模式** (纯黑 #000000 for OLED)

### 设计原则
1. **简洁** - 减少视觉干扰，专注终端内容
2. **高效** - 快捷键、手势操作
3. **平板优先** - 双栏布局、分屏优化

---

## 2. 色彩系统

### 主色调
- **Primary**: #2563EB (蓝色 - 专业感)
- **Secondary**: #10B981 (绿色 - 成功状态)
- **Error**: #EF4444 (红色 - 错误状态)

### 深色主题
- **Background**: #0F0F0F
- **Surface**: #1E1E1E
- **Terminal Background**: #000000 (纯黑)

### 终端配色 (Dracula 主题)
| 颜色 | Hex | 用途 |
|------|-----|------|
| Black | #21222C | 普通文本 |
| Red | #FF5555 | 错误/删除 |
| Green | #50FA7B | 成功/执行 |
| Yellow | #F1FA8C | 警告 |
| Blue | #BD93F9 | 链接/路径 |
| Magenta | #FF79C6 | 关键字 |
| Cyan | #8BE9FD | 提示 |
| White | #F8F8F2 | 高亮 |

## 3. 布局设计

│  连接列表    │     终端区域         │
│  (250px)     │     (自适应)         │
│              │                      │
│  - Server 1  │  $ _                 │

### 手机布局
- 单栏布局
- 底部导航切换连接列表/终端

## 4. 交互设计

### 手势操作
| 手势 | 功能 |
|------|------|
| 双指缩放 | 字体大小 |
| 三指左滑 | 切换会话 |
| 长按 | 上下文菜单 |
| 双击 | 复制/粘贴 |

### 键盘快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl+T | 新标签页 |
| Ctrl+W | 关闭标签页 |
| Ctrl+Tab | 切换标签页 |
| Ctrl+Shift+T | 新连接 |
| F1-F12 | 功能键映射 |
| PageUp/Down | 滚动历史 |

## 5. 设计灵感

### 参考应用
1. **Termius** - 现代 UI、跨平台
2. **Blink Shell** - iOS 标杆、键盘支持
3. **Hyper** - 桌面终端美学

### 设计趋势
- 极简主义
- 高对比度
- 大字体友好
- 手势优先
